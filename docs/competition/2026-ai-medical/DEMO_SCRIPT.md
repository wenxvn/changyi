# 三分钟演示脚本

## A · 普通病例（约 45 秒）

输入：`皮肤瘙痒一周，没有呼吸困难，也没有发烧`。

展示否定理解、`ROUTINE`、皮肤科方向、医院/医生资源、距离和“为什么推荐”。强调这是就医方向参考，不是皮肤病诊断。

## B · 信息不足（约 45 秒）

输入：`最近总是头晕`。

展示普通安全状态下的动态追问：持续时间/严重程度/是否突然出现和危险信号；补充答案后再继续路线生成，追问与当前状态都不等于诊断结论。

## C · 危险病例（约 60 秒）

输入：`胸口压榨样疼痛，喘不过气，还一直冒冷汗`。

展示 Safety Gate 先于疾病候选，第一屏出现“需要优先进行紧急医疗评估”、附近急诊和 120；确认普通医生排行榜没有抢占主视觉，解释急症排序不会被公交/骑行权重带偏。
