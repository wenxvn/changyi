# 交通样本索引边界计划

状态：已完成

## 目标

把交通样本行按 `hospital_id` 建立 station/taxi/bike 索引的无副作用逻辑提取到 recommendation domain，保持现有缓存懒加载、重复 ID 的覆盖顺序和下游交通展示/排序行为不变。

## 非目标

- 不修改公交、出租车、自行车样本的计算口径或数据来源。
- 不把样本索引解释为实时路况、到院时间或医疗事实。
- 不改变 `_TRANSIT_ACCESS_CACHE` 的生命周期和 `app.py` 中的数据加载职责。
