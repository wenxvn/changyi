# 急症候选资格边界计划

状态：进行中

## 目标

把急症医生兜底路径中“医院是否具备急诊资格”的纯判断提取到 candidate domain，继续保持 `app.py` 负责候选遍历、医院查找、交通计算、评分、结果组装和排序。

## 非目标

- 不改变急症候选全集、医院查找、排序键、评分公式或公共响应字段。
- 不新增急症医学规则，不调整 Safety Gate、红旗症状或普通推荐路径。
- 不引入新的实时急诊可用性承诺，也不把 `emergency` 字段解释为临床分诊结论。

## 步骤

- [ ] 在 `candidates.py` 新增显式输入的急症医院资格判断。
- [ ] 用函数替换 `app.py` 急症医生兜底循环中的内联判断。
- [ ] 增加 true/false/缺失医院边界测试。
- [ ] 更新进度、历史、复核、状态、架构和风险记录。

## 验收与回滚

- 既有急症兜底行为快照和 API smoke 保持不变。
- 目标测试、全量 pytest、Safety Eval、API smoke、编译检查、数据校验和快照检查通过。
- 回滚方式：恢复 `app.py` 内联资格判断并移除本切片函数、测试和记录。

## 风险

该切片只移动布尔资格判断，属于 L2/L3 边界附近的结构性迁移；仍需人工/专业复核急症规则和候选策略，不能把候选资格当作医疗建议。
