# 医院 candidate 组合边界计划

状态：已完成

## 目标

把单个医院候选的 feature 组合、风险惩罚、综合分数、解释和稳定结果组装提取为纯 domain 函数，保持医院遍历、交通字段准备、权重、字段、排序和重排行为不变。

## 非目标

- 不改变医院候选全集、距离计算、交通样本口径或缓存生命周期。
- 不修改医学规则、推荐权重、风险惩罚数值、解释文案或 rerank 约束。
- 不把系统内部分数解释为医院官方评级、临床结论或实时可达性承诺。

- [x] 用函数替换 `app.py` 医院循环中的单候选组合逻辑。

## 验收与回滚

- 对同一组医院、交通、位置和 triage 输入，结果字段和推荐快照保持一致。
- 全量 pytest、API 烟雾、Safety Eval、数据校验、编译检查和快照检查通过。
- 回滚方式：恢复 `app.py` 单候选组合代码并移除本切片函数、测试和记录。
