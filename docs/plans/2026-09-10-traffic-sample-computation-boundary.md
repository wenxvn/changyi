# 交通样本计算边界计划

状态：已完成

## 目标

把公交、出租车、自行车站点和车辆分布四类“医院 × 脱敏样本”计算提取为纯 domain 函数，保持样本字段、距离阈值、分数分档、排序和缺失数据行为不变。

## 非目标

- 不修改原始交通数据、来源、时间口径或脱敏状态。
- 不把交通样本宣称为实时路况、预计到院时间或医疗事实。
- 不改变 `_TRANSIT_ACCESS_CACHE` 生命周期、`_bus_route_stats` 汇总或推荐中急症禁用交通权重的策略。

## 步骤

- [x] 用函数替换 `app.py` 的样本计算循环，保留数据加载适配。
- [x] 增加阈值、缺失坐标、空样本和排序行为测试。
- [x] 更新进度、历史、复核、状态、架构、质量和风险记录。

## 验收与回滚

- 给定相同输入，四类结果与旧实现逐字段一致。
- 全量 pytest、API 烟雾、Safety Eval、数据校验、编译检查和快照检查通过。
- 回滚方式：恢复 `app.py` 四类内联循环并移除本切片函数、测试和记录。

## 验证记录

- 全量验证结果已记录在 `docs/progress/2026-09-10-traffic-sample-computation-boundary.md`。

## 风险

本切片是 L2 数据边界重构；它不改变医疗排序，但必须保留自行车仅展示、不参与医疗推荐排序的既有约束。
