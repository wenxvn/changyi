# 急症医生兜底评分边界计划

状态：已完成

## 目标

把急症医生兜底候选的既有资历、医院质量、可及性和优先级计算提取为可测试的纯函数，保持急诊医院过滤、分数公式、排序和结果字段不变。

## 非目标

- 不改变急症候选筛选条件、急诊能力判断或候选数量。
- 不修改医生职称/手术经验的医学解释、权重、Safety Gate 或 API 输出。
- 不新增临床判断、急救指令或把优先级分数当成医疗结论。

- [x] 用函数替换 `app.py` 兜底路径中的内联评分计算。
- [x] 增加职称、手术经验、医院质量、可及性和边界回归测试。
- [x] 更新进度、历史、复核、状态、架构、Safety Card、质量和风险记录。

## 验收与回滚

- 既有急症医生兜底结果字段和优先级排序保持；普通医生路径不受影响。
- 全量 pytest、API 烟雾、Safety Eval、数据校验、编译检查和快照检查通过。
- 回滚方式：恢复 `app.py` 急症兜底内联评分并移除本切片函数、测试和记录。
