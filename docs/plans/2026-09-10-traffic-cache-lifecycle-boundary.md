# 交通缓存生命周期边界计划

状态：已完成

## 目标

把交通样本索引的懒加载/复用/清空生命周期从 `app.py` 全局变量中提取为可测试的 infrastructure cache seam，保持首次构建、后续复用和现有推荐行为不变。

## 非目标

- 不改变交通样本计算、索引、数据加载、排序或推荐权重。
- 不引入未经验证的 TTL、后台刷新、实时交通或跨进程共享缓存。
- 不改变现有 `_TRANSIT_ACCESS_CACHE` 的兼容名称和默认懒加载时机。

## 步骤

- [x] 新增可清空的 lazy cache 基础设施类。
- [x] 用 cache seam 替换 `app.py` 的 `None` 哨兵和 global 写入。
- [x] 增加只构建一次、清空后重建和返回值行为测试。
- [x] 更新进度、历史、复核、状态、架构、质量和风险记录。

## 验收与回滚

- builder 在首次 `get()` 前不执行，首次后只执行一次；`clear()` 后下一次重新构建。
- 推荐 API、交通统计和快照保持不变。
- 全量 pytest、API 烟雾、Safety Eval、数据校验、编译检查和快照检查通过。
- 回滚方式：恢复 `None` 哨兵实现并移除 cache 类、测试和记录。

## 验证记录

- 目标回归：cache、交通、API 和 Safety 相关测试 23/23 通过。
- 全量验证结果已记录在 `docs/progress/2026-09-10-traffic-cache-lifecycle-boundary.md`。

## 风险

本切片只治理本进程内的懒加载生命周期，不解决数据新鲜度、跨进程一致性或实时交通能力；这些问题继续留在开放风险中。
