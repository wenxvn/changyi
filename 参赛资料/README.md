# 参赛资料

本目录存放 2026 AIC「AI+医学」赛道的官方文件、审计报告与技术报告写作材料。

## 文件清单

| 文件 | 用途 | 说明 |
| --- | --- | --- |
| `official-rules.pdf` | 官方竞赛规则与作品提交要求 | 从赛道官网附件取得，2 页 |
| `AIC·AI+医学技术报告参考大纲.pdf` | 官方技术报告大纲模板 | 6 页，含排版规范 |
| `AIC·AI+医学技术报告参考大纲.docx` | 官方大纲 Word 模板 | 可直接用于成文 |
| `TECHNICAL_REPORT_OUTLINE.md` | 本项目技术报告写作大纲 | 章节映射、字数预算、数字口径冻结 |
| `changyi-audit.md` | 2026-10-02 参赛审计报告 | P0 4 项 / P1 7 项 / P2 3 项 |
| `api-smoke.json` | 审计期 API 冒烟结果 | 只读证据 |
| `audit-probes.json` | 审计期探针结果 | 只读证据 |

## 使用约定

1. 官方文件（`official-rules.pdf`、`AIC·AI+医学技术报告参考大纲.*`）保持原样，不改内容、不改文件名。
2. 审计报告与探针证据为 2026-10-02 快照，其中的算法数字已被 `docs/evaluation/COMPETITION_ALGORITHM_EVIDENCE.md` 的修复后口径取代；引用前先核对。
3. 本目录**不得**放入任何含学校名称、LOGO、指导教师、学号、纳税人识别号或真实患者信息的材料。报名费发票等财务凭证请留在仓库之外。

## 红线

技术报告、演示视频、答辩 PPT、佐证 PDF 与网盘代码包均需匿名。提交前按 `TECHNICAL_REPORT_OUTLINE.md` 第 6 节逐项检查。
