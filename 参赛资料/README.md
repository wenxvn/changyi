## 答辩稿使用

主讲建议 8–10 分钟，第 16–18 页为备答。实际答辩时限以主办方通知为准；规则未规定 PPT 时长，不套用演示视频的 3–5 分钟要求。需要讲稿时使用 PowerPoint「备注/演讲者视图」。报名系统要求上传 PDF，PPTX 用于后续修改和现场讲解。

答辩围绕“安全优先、方向可解释、路径可继续”展开，开场连接用户问题、服务缺口、系统思路与直接证据，结尾集中呈现三项服务价值。主讲包含安全状态控制、三类行动路径和常州资源衔接；第16–18页为分类研究、数据协议与证据来源。

截图采自2026-10-22本地网站，主诉示例均为合成。Safety数字对应142个固定工程样例；分类结果对应公开混合文本的离线研究，研究模型以 `RESEARCH_ONLY` 管理；医院和医生数量对应城市目录记录。地图底图署名OpenStreetMap contributors，实时接诊以医疗机构确认为准。大纲、页面正文和讲稿备注使用项目内容与证据说明。

## 使用约定

1. 官方文件（`official-rules.pdf`、`AIC·AI+医学技术报告参考大纲.*`）保持原样，不改内容、不改文件名。
2. 审计报告与探针证据为 2026-10-02 快照，其中的算法数字已被 `docs/evaluation/COMPETITION_ALGORITHM_EVIDENCE.md` 的修复后口径取代；引用前先核对。
3. 本目录**不得**放入任何含学校名称、LOGO、指导教师、学号、纳税人识别号或真实患者信息的材料。报名费发票等财务凭证请留在仓库之外。

## 红线

技术报告、演示视频、答辩 PPT、佐证 PDF 与网盘代码包均需匿名；匿名要求见官方规则及[匿名审计清单](../docs/competition/2026-ai-medical/SUBMISSION_WORKFLOW.md)。
